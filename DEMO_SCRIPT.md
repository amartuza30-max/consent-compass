# Consent Compass — two-minute demo script

Target length: 95–110 seconds. The entrant should appear or speak in the recording and explain the project in their own voice.

## 0:00–0:15 — problem

“Hi, I’m Ali, and this is Consent Compass. Agents can send files, publish content, make purchases, or delete data, but people need a clear permission plan before those actions happen.”

Show the landing view and the “Local runtime” indicator.

## 0:15–0:35 — proposed action

“Consent Compass is a portable two-agent network that runs entirely in the browser. I’ll ask it to email a completed report to an external sponsor, involving contact information and a private file.”

Show the completed action form, destination, and selected data chips. Click **Build permission plan**.

## 0:35–1:05 — agent network and result

“The consent coordinator frames the request and delegates analysis to the risk analyst. A declared local capability evaluates transmission, reversibility, financial impact, public visibility, and sensitive data. Execution is bounded by a step limit and a time limit.”

Show the high-risk badge, zero network calls, reasons, and checkpoints. Briefly show the three-stage architecture at the bottom of the page.

## 1:05–1:28 — human checkpoint

“Instead of acting automatically, the network returns a human checkpoint. I verify the destination, the data categories, and the intended effect. Only then can I record approval.”

Select the review checkbox and click **Record approval**.

## 1:28–1:42 — auditability

“The decision is recorded locally and can be exported as audit-ready JSON. Nothing is transmitted by the demo, and no account, API key, or backend is required.”

Click **Export audit JSON**.

## 1:42–1:55 — close

“Consent Compass makes human control portable across the open agentic web: inspectable agents, declared capabilities, bounded execution, and explicit consent before consequential action.”

End on the architecture section or repository README.
