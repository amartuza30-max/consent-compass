# Submission screenshot checklist

Capture at 1440 × 900 or larger, with browser chrome cropped where practical.

1. **Hero and input** — landing view with the default email example and selected data chips.
2. **Decision map** — completed high-risk result showing zero network calls, reasons, and all approval checkpoints.
3. **Approval recorded** — reviewed checkbox selected and “Approval recorded locally” visible.
4. **Portable architecture** — the three-stage consent coordinator → risk analyst → human checkpoint flow.

Use screenshots 1–3 in the submission gallery. Keep screenshot 4 available for the project description or repository.
